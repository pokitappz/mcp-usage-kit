# mcp-usage-tower

The Tower hot path for MCP authentication, protocol guards, task attribution,
authorization-aware caching, response observation, and usage recording.

Most applications should depend on the `mcp-usage-kit` facade. Use this crate
directly to integrate the lower-level edge service with custom components.
